# bondiallibres
BondiaLlibres és una factoria de còmics i llibres en català 100% gratuïta i sense ànim de lucre. Un espai obert i lliure de barreres econòmiques per a infants i joves, ple d'històries que treuen un somriure, com el caos de 'La Gina i els nens' o 'Meh i Llana'. Gaudeix de la lectura en llibertat!
