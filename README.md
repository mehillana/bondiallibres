## 🛠️ Detalls del Projecte i Desenvolupament

Aquest repositori conté tot el codi de la plataforma web i els fitxers de distribució dels còmics en format PDF d'alta resolució.

### 📐 Arquitectura del Repositori:
```text
├── index.html          # Pàgina principal del catàleg
├── css/                # Estils i disseny adaptatiu (Mobile First)
├── img/                # Portades, il·lustracions i avatars dels personatges
├── pdf/                # Còmics complets optimitzats per a web i impressió
├── LICENSE.md          # Protecció legal Creative Commons
└── README.md           # Aquest fitxer informatiu
```

### ⚙️ Característiques Tècniques:
* **Interfície Neta i Intuïtiva:** Dissenyada perquè els nens puguin navegar fàcilment.
* **Sense Registres:** Accés immediat al contingut, sense correus ni contrasenyes.
* **Imprimible:** Els PDF estan optimitzats per a impressores domèstiques i escolars.
